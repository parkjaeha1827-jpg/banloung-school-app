# ប្រព័ន្ធគ្រប់គ្រងសាលាបឋមសិក្សា បាន្លួង
## Ban Loung Primary School Management System

កម្មវិធីនេះត្រូវបានបង្កើតឡើងយ៉ាងសម្រិតសម្រាំងសម្រាប់ **សាលាបឋមសិក្សា បាន្លួង** (ស្រុកព្រៃកប្បាស ខេត្តតាកែវ) ដោយគោរពតាមគម្រូស្តង់ដា ១០០% របស់ក្រសួងអប់រំ យុវជន និងកីឡា។

---

### លក្ខណៈពិសេសចម្បង (Key Features)

១. **ផ្ទាំងគ្រប់គ្រងរួម (Dashboard / Overview)**
   - បង្ហាញចំនួនសិស្សសរុប និងសិស្សស្រី
   - បង្ហាញចំនួនគ្រូបង្រៀនសរុប និងគ្រូស្រី
   - ក្រាបសសរ (Bar Chart): បង្ហាញការបែងចែកសិស្សប្រុស និងស្រី តាមកម្រិតថ្នាក់នីមួយៗ
   - ក្រាបផ្លិត (Pie/Donut Chart): បង្ហាញសមាមាត្រភេទសិស្ស (ប្រុស/ស្រី)
   - តម្រងជ្រើសរើសឆ្នាំសិក្សា (២០២៥-២០២៦, ២០២៣-២០២៤, ២០២២-២០២៣)

២. **បញ្ជីឈ្មោះសិស្ស (Student Roster - 100% តាមគម្រូក្រសួងអប់រំ)**
   - ទម្រង់ក្បាលលិខិតផ្លូវការ៖
     - ព្រះរាជាណាចក្រកម្ពុជា ជាតិ សាសនា ព្រះមហាក្សត្រ (ស្ថិតនៅចំកណ្ដាល)
     - សាលាបឋមសិក្សា បាន្លួង (ស្ថិតនៅខាងឆ្វេងក្រោមបន្តិច)
     - បញ្ជីរាយនាមឈ្មោះសិស្សថ្នាក់ទី ... (ឆ្នាំសិក្សា ...)
   - អក្សរពុម្ពផ្លូវការ៖ **Khmer OS Battambang** និង **Khmer OS Muol Light** ទំហំ **11px**
   - លុបបន្ទាត់ចែកបញ្ឈររវាង (គោត្តនាម  នាម), (ថ្ងៃ ខែ ឆ្នាំ), (ភូមិ ឃុំ), (គោត្តនាម នាម មុខរបរ)
   - ផ្នែកហត្ថលេខាខាងក្រោម៖
     - នាយកសាលា៖ ទុកចន្លោះទំនេរសម្រាប់ចុះហត្ថលេខា និងបោះត្រាក្រហម (គ្មានឈ្មោះបោះពុម្ពពីក្រោម)
     - គ្រូប្រចាំថ្នាក់៖ មានកាលបរិច្ឆេទដែលអាចចុចបំពេញ ឬកែប្រែបានផ្ទាល់ (Inline Edit)
   - **ក្រដាស A4 ផ្ដេក (A4 Landscape)** ស្រស់ស្អាត សមស្របសម្រាប់ការបោះពុម្ព
   - មុខងារ **ទាញយកគម្រូ File Excel (Download Template)** ដូចក្នុងប្រព័ន្ធ ១០០%
   - មុខងារ **នាំចូល File Excel/CSV (Import)** និងបិទភ្ជាប់ (Paste) ទិន្នន័យ
   - មុខងារ **នាំចេញ File Excel (Export XLSX/CSV)**
   - មុខងារ **បោះពុម្ព (Print & PDF)**

៣. **វត្តមានសិស្សប្រចាំថ្ងៃ (Daily Attendance - ភ្ជាប់ទិន្នន័យស្វ័យប្រវត្តិ)**
   - ជ្រើសរើសកាលបរិច្ឆេទ និងថ្នាក់រៀន
   - កត់ត្រាវត្តមានរហ័ស៖ **វត្តមាន**, **មានច្បាប់**, **ឥតច្បាប់** ព្រមទាំងបញ្ចូលមូលហេតុ
   - **រក្សាទុក និងភ្ជាប់ទិន្នន័យស្វ័យប្រវត្តិនឹងវត្តមានប្រចាំខែ (Auto-Sync)**៖ រាល់ពេលជ្រើសរើសស្ថានភាពវត្តមាន ប្រព័ន្ធនឹងរក្សាទុក និងបញ្ជូនទិន្នន័យទៅវត្តមានប្រចាំខែភ្លាមៗ ដោយមិនបាច់ចុចប៊ូតុងរក្សាទុកដោយដៃឡើយ
   - ប៊ូតុង **"វត្តមានទាំងអស់"** សម្រាប់ចុះវត្តមានសិស្សទាំងអស់ក្នុងថ្នាក់ដោយចុចតែមួយដង
   - របារស្ថិតិវត្តមានផ្ទាល់ (Live Counters): បង្ហាញចំនួនសិស្សសរុប វត្តមាន ច្បាប់ ឥតច្បាប់ និងអត្រា % ប្រចាំថ្ងៃ

៤. **វត្តមានសិស្សប្រចាំខែ (Monthly Attendance Register - តាមលំនាំស្តង់ដា)**
   - តារាងកាលវិភាគ ៣១ ថ្ងៃ តាមក្បួនសៀវភៅហៅឈ្មោះបឋមសិក្សា
   - **និមិត្តសញ្ញាវត្តមានជាក់ស្ដែងតាមលំនាំ**៖
     - ជ្រើសរើស **វត្តមាន** → បង្ហាញសញ្ញាគ្រីស **`✓`** (ពណ៌បៃតង)
     - ជ្រើសរើស **មានច្បាប់** → បង្ហាញអក្សរ **`P`** (ពណ៌លឿងទុំ)
     - ជ្រើសរើស **ឥតច្បាប់** → បង្ហាញអក្សរ **`A`** (ពណ៌ក្រហម)
     - ថ្ងៃមិនទាន់កត់ត្រា/ចុងសប្តាហ៍ → បង្ហាញសញ្ញា **`-`**
   - គណនាសរុបអវត្តមាន (**ច្បាប់**, **ឥត**, **សរុប**) និងភាគរយវត្តមានសិស្សម្នាក់ៗ
   - ជួរសរុបខាងក្រោម៖ បង្ហាញចំនួនសិស្សអវត្តមានសរុបប្រចាំថ្ងៃនីមួយៗក្នុងខែ
   - តម្រងជ្រើសរើសខែ (មករា ដល់ ធ្នូ) និងឆ្នាំ
   - មុខងារ **ទាញយកជា File Excel** និង **បោះពុម្ពតារាងប្រចាំខែ**

៥. **គ្រប់គ្រងពិន្ទុ និងចំណាត់ថ្នាក់សិស្ស (Scores & Rankings)**
   - មុខវិជ្ជា៖ ភាសាខ្មែរ, គណិតវិទ្យា, វិទ្យាសាស្ត្រ, សិក្សាសង្គម, អប់រំកាយ/កីឡា, សិល្បៈ
   - គណនាពិន្ទុសរុប, មធ្យមភាគ, និទ្ទេស (ល្អប្រសើរ, ល្អណាស់, ល្អ, មធ្យម, ខ្សោយ), ចំណាត់ថ្នាក់ (Rank), និងលទ្ធផល (ជាប់/ធ្លាក់)
   - ប័ណ្ណតាមដានការសិក្សាផ្ទាល់ខ្លួន (Report Card)
   - តារាងកិត្តិយសសិស្សពូកែ (Honor Roll - Top 5)

៦. **គ្រប់គ្រងគ្រូបង្រៀន (Teacher Management)**
   - បញ្ជីរាយនាមគ្រូបង្រៀនទាំង ៧ រូប (ង៉ែត សារុន, លី ស្រីនូ, ផាន ផុស, លី មករា, ក្រូយ ចាន់ធារ៉ា, សុខ ស្រីនាង, ញឹម ស៊ីវថា)
   - បន្ថែម, កែប្រែ, លុបព័ត៌មានគ្រូ

៧. **បន្ទប់ប្រឡងតេស្ដស្តង់ដា (Standard Exam Rooms)**
   - បន្ទប់ប្រឡងលេខ ១ ដល់ ៦ សម្រាប់ថ្នាក់ទី១ ដល់ ទី៦
   - បញ្ជីឈ្មោះសិស្សតាមបន្ទប់ និងលេខតុ

### របៀបបើកដំណើរការ (How to Run)

#### វិធីទី១៖ បើកផ្ទាល់តាម Browser (មិនបាច់ប្រើ Server)
- គ្រាន់តែ Double-click លើ File `index.html` នោះវានឹងបើកដំណើរការភ្លាមៗក្នុង Chrome, Edge ឬ Browser ណាមួយ!

#### វិធីទី២៖ ដំណើរការជាមួយ Python Server
- បើក Terminal ឬ PowerShell រួចចូលទៅកាន់ Folder គម្រោង៖
  ```bash
  cd C:\Users\PC\.gemini\antigravity\scratch\banloung-school-app
  python app.py
  ```
- បើក Browser ទៅកាន់៖ `http://localhost:5000`
